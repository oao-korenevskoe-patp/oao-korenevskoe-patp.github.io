# 🚌 ОАО «Коренёвский ПАТП» — Официальный портал и форум предприятия OMSI 2

Современный, быстрый и стильный веб-сайт/форум виртуального пассажирского автотранспортного предприятия для популярного симулятора **OMSI 2: Der Omnibussimulator**.

Выполнен в строгом **тёмно-синем стиле** с акцентами транспортной диспетчерской, золотистыми номерами маршрутов и полным набором рабочих функций.

---

## 🌟 Возможности и структура сайта

Форум строго сфокусирован на ключевых рабочих процессах ПАТП:

### 1. 📋 Раздел «Отчеты» (Сдача путевых листов)
- Водители после завершения рейса в OMSI 2 сдают отчет за смену:
  - Выбор маршрута (городские, пригородные, экспрессы)
  - Марка автобуса и бортовой / гос. номер (ЛиАЗ, ПАЗ, НефАЗ, Икарус, МАЗ)
  - Число кругорейсов и перевезенных пассажиров
  - Сумма выручки с проданных билетов в рублях
  - Соблюдение графика движения (по расписанию / опоздание / сход)
  - Ссылка на скриншоты (тахограф, касса IBIS, путевой лист из игры)
  - Комментарий водителя
- Диспетчерский состав и Руководитель проверяют путевые листы:
  - Кнопка **«Принять отчет»** с добавлением служебной резолюции
  - Кнопка **«Отклонить»** с указанием причины
  - Автоматический подсчёт кассы предприятия и сданных рейсов

### 2. 🏖️ Раздел «Отгул» (Заявления на отсутствие)
- Водители могут заблаговременно подать заявление на отгул / отпуск при форс-мажорах:
  - Семейные обстоятельства
  - Техническое обслуживание ПК, руля (Logitech, Thrustmaster, Moza)
  - Учёба, экзамены и сессия
  - Плановый отпуск
  - Больничный
- Выбор дат «С» по «По» и подробное объяснение
- Зам. по личному составу и Руководитель имеют полномочия согласовать или отказать в отгуле с официальной резолюцией в табель

### 3. 🗺️ Раздел «Наши маршруты» (Маршрутная сеть)
- Карточки всех действующих маршрутов предприятия с полными данными:
  - **№ 1**: Автовокзал «Коренёво» — Микрорайон Северный (городской)
  - **№ 104**: ПАТП «Коренёво» — с. Коренёво — д. Заречье (пригородный)
  - **№ 23**: Кольцевой: Рынок — Привокзальная — Больничный комплекс — ПАТП
  - **№ 55э**: Экспресс: Аэропорт «Коренёво» — Гостиница «Центральная»
  - **№ 7**: Ночной дежурный рейс (развозка водителей)
- Указание протяженности, времени хода, интервала, кодов для IBIS/HOF (`KORENEVO_PATP_v2.hof`), перечня остановок и допущенных моделей автобусов
- Кнопка «Сдать отчет по маршруту» с автоматической подстановкой в форму отчета

## 👥 Роли предприятия и права доступа

В системе реализованы 4 роли с отличительными цветовыми бейджами:

1. 🔴 **Руководитель / Главный Администратор** (`director`):
   - **ФИО:** `Владислав Корней Коршунов`
   - **Пароль администратора:** `23ubd7kW14!`
   - Полный доступ ко всем функциям предприятия.
   - Одобрение отчетов и согласование отгулов.
   - Управление кадрами и маршрутами.
2. 🟣 **Зам.Руководителя по личному составу** (`hr`):
   - Отдел кадров, учет рабочего времени.
   - Рассмотрение и согласование заявлений на отгулы и отпуска.
3. 🔵 **Зам.Руководителя по диспетчерскому составу** (`dispatch`):
   - Организация перевозок и контроль выпуска на линию.
   - Проверка путевых листов, выручки и скриншотов отчетов за смену.
4. 🟢 **Водитель** (`driver`):
   - Сдача путевых листов за смену.
   - Подача заявлений на отгул.
   - Просмотр маршрутной сети и статусов своих отчетов.

> 💡 **Быстрое переключение для тестирования**: В верхней панели сайта прямо под шапкой встроена панель быстрого переключения любой из 4 ролей в один клик.

## 🌐 Бесплатный хостинг (Подборка и пошаговая инструкция)

Сайт создан как современное автономное веб-приложение (HTML5 + CSS + JavaScript) с сохранением всех данных в `localStorage`. Это означает, что его можно разместить на **100% бесплатном хостинге навсегда без каких-либо расходов и без необходимости администрировать сервер**!

### Вариант 1: Netlify Drop (Самый лёгкий, займет 30 секунд, БЕЗ консоли и БЕЗ Git)
1. Откройте страницу: **[https://app.netlify.com/drop](https://app.netlify.com/drop)**
2. Перетащите папку `korenevskoe-patp` мышкой в пунктирное поле на странице.
3. Через несколько секунд сайт мгновенно развернется в интернете.
4. Вы получите бесплатную защищенную ссылку вида: `https://korenevskoe-patp.netlify.app`.
5. Ссылку можно сразу отправлять водителям вашего виртуального ПАТП!

---

### Вариант 2: GitHub Pages (Бесплатно навсегда, удобно для совместной работы)
1. Создайте бесплатный аккаунт на [GitHub](https://github.com/).
2. Создайте новый публичный репозиторий, например `korenevskoe-patp`.
3. Загрузите файлы `index.html`, `style.css`, `app.js` в репозиторий.
4. Откройте **Settings** (Настройки) -> вкладку **Pages**.
5. В блоке **Branch** выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
6. Через 1 минуту сайт будет доступен по адресу:
   `https://ваш-логин.github.io/korenevskoe-patp/`

---

### Вариант 3: Vercel (Мгновенный деплой и собственный домен)
1. Зарегистрируйтесь на [Vercel](https://vercel.com/) (бесплатный тариф Hobby).
2. Нажмите **Add New Project** -> выберите загруженный GitHub-репозиторий или используйте утилиту Vercel CLI.
3. Нажмите **Deploy**.
4. Сайт будет опубликован с бесплатным SSL-сертификатом и высокой скоростью по всему СНГ.

---

### Дополнительно: Подключение многопользовательской базы данных (Supabase / Firebase)
Если вам потребуется централизованная облачная синхронизация между всеми участниками (чтобы водители из других городов видели отчеты друг друга на одном общем сервере в реальном времени):
- Рекомендуется бесплатный тариф **Supabase** (500 МБ PostgreSQL бесплатно навсегда, встроенный Auth и Realtime).
- В `app.js` функции `saveReports()` и `loadFromStorage()` легко дополняются обращением к REST API Supabase.
