Как выложить этот сайт в интернет за 2 минуты без оплаты

1 Netlify Drop (Самый простой вариант, без установки программ)

  1. Откройте сайт app.netlify.com/drop
  2. Перетащите папку с файлами сайта (korenevskoe-patp) в окно браузера.
  3. Через 10 секунд сайт запустится и выдаст вам готовую бесплатную ссылку (вида patp-korenevo.netlify.app) с бесплатным HTTPS!

2 Vercel (Быстрый хостинг с поддержкой доменов)

  1. Зарегистрируйтесь бесплатно на vercel.com через GitHub или почту.
  2. Импортируйте проект или выполните команду npx vercel в папке.
  3. Получите адрес *.vercel.app с быстрой доставкой по всему миру.

3 GitHub Pages (100% бесплатно навсегда)

  1. Создайте репозиторий на github.com и загрузите туда файлы index.html, style.css, app.js.
  2. Зайдите в Settings -> Pages репозитория.
  3. Выберите ветку main / root и нажмите Save.
  4. Ваш сайт станет доступен по адресу https://ваше-имя.github.io/репозиторий/.

Синхронизация: ожидает

Пошаговая инструкция подключения общей базы (1-2 минуты, бесплатно):

  1. Откройте сайт console.firebase.google.com (вход под любой почтой Google).
  2. Нажмите «Создать проект» (введите любое название, например korenevskoe-patp).
  3. В меню слева найдите раздел «Realtime Database» → нажмите «Создать базу данных».
  4. Выберите регион (например, Бельгия или США) и выберите режим «Тестовый режим» (Start in test mode), чтобы правила разрешали чтение и запись.
  5. Скопируйте адрес вашей базы (вверху страницы, начинается на https://...) и вставьте в поле выше.
  6. Нажмите кнопку «Подключить и сохранить».
💡 Как поделиться с водителями: Вы можете отправить ссылку на сайт с параметром #db=ВАША_ССЫЛКА_FIREBASE (например: https://oao-korenevskoe-patp.github.io/#db=https://ваш-проект-default-rtdb.firebaseio.com/), и у всех водителей база подключится автоматически при первом открытии!
